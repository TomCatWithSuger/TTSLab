# 语音合成实验步骤

## 实验内容

使用ESPnet-TTS预训练模型对英文文本进行语音合成，对比FastSpeech 2与Tacotron 2在CPU环境下的合成效果和推理性能，并通过生成音频、波形图、语谱图、RTF、模型大小和MOS分析实验结果。

本实验使用CPU和Docker Compose，不包含模型训练、模型微调、GPU/CUDA、多说话人语音合成或中文语音合成。

## 实验步骤

### 步骤1：准备运行环境

在Windows、macOS或Linux上安装并启动Docker Desktop或Docker Engine。Python、CPU版PyTorch、ESPnet、声码器和音频处理依赖全部安装在容器内，宿主机不需要安装Python、CUDA或NVIDIA工具。

安装完成后验证：

```bash
docker run hello-world
docker compose version
```

### 步骤2：创建Docker运行环境

进入项目根目录并构建CPU镜像：

```bash
cd TTSLab
docker compose build
```

首次构建会下载Python基础镜像和项目依赖。未修改`Dockerfile`或`requirements.txt`时，后续构建会复用缓存。

### 步骤3：准备测试文本

测试文本保存在：

```text
data/texts/test.txt
```

每行使用`样本ID|英文文本`格式，例如：

```text
001|The weather is very nice today.
002|Speech synthesis converts written text into natural-sounding speech.
003|Artificial intelligence is changing our daily life.
```

项目默认准备10条英文文本，包含短句、长句、数字、缩写和标点。两个模型使用完全相同的测试文本。

### 步骤4：快速运行实验

执行完整流程：

```bash
docker compose run --rm app
```

第一次运行时，程序会自动下载FastSpeech 2、Tacotron 2和HiFi-GAN预训练模型，并缓存到`models/pretrained/`。后续运行会直接使用缓存。

先使用一条文本进行快速测试：

```bash
docker compose run --rm app \
    python src/run_experiment.py --limit 1
```

只运行其中一个模型：

```bash
docker compose run --rm app \
    python src/run_experiment.py --models fastspeech2
```

```bash
docker compose run --rm app \
    python src/run_experiment.py --models tacotron2
```

### 步骤5：了解代码主要流程

主程序按以下顺序执行：

1. **读取测试文本**
   - 从`data/texts/test.txt`读取英文文本。
   - 检查文本格式和重复样本ID。

2. **检查并获取预训练模型**
   - 使用FastSpeech 2和Tacotron 2预训练模型。
   - 使用相同的HiFi-GAN声码器生成波形。
   - 模型存在时跳过下载，缺失时自动下载并缓存。

3. **执行语音合成**
   - 先执行一次预热推理。
   - 使用FastSpeech 2合成全部测试文本。
   - 使用Tacotron 2合成相同文本。
   - 保存WAV并记录推理时间、音频时长和RTF。

4. **生成实验结果**
   - 绘制两个模型的波形图和语谱图。
   - 统计平均RTF、模型参数量和模型检查点大小。
   - 创建MOS人工评分表。

### 步骤6：查看实验结果

实验结果保存在：

```text
outputs/
├── audio/
│   ├── fastspeech2/         # FastSpeech 2生成的WAV
│   └── tacotron2/           # Tacotron 2生成的WAV
├── figures/                 # 波形图和语谱图
└── metrics/
    ├── benchmark.json       # RTF和模型规模指标
    └── mos.csv              # MOS人工评分表
```

完成后试听两个模型生成的音频，查看对应的波形图和语谱图，并比较`benchmark.json`中的平均RTF、参数量和模型大小。

MOS评价由5～10名参与者对音频自然度进行1～5分评分，最后分别计算FastSpeech 2和Tacotron 2的平均MOS。
